## 接收方如何复现

1. 取得仓库并切换到 `delivery-20261113`，或解压交付源码 ZIP，在包含 README 的目录打开终端。
2. 准备 Python 3.11 或更新版本、本地 FFmpeg 和 FFprobe。实际验证版本为 Python 3.13.2、FFmpeg/FFprobe 9.0.2。Python 代码只使用标准库，无须 `pip install`。
3. 把获准使用的三条视频放到本地 `aios-shot-materials/`，文件名为 `sample-01.mp4`、`sample-02.mp4`、`sample-03.mp4`。也可在命令中直接指定其他本地文件路径。
4. 若 FFmpeg/FFprobe 已加入 PATH，在项目根目录运行：

```sh
python -m beauty_cut preview "aios-shot-materials/sample-01.mp4" "aios-shot-materials/sample-02.mp4" "aios-shot-materials/sample-03.mp4" --output-dir outputs/delivery-review --threshold 5 --timeout 600
```

便携工具未加入 PATH 时，在上述命令后分别追加 `--ffmpeg "实际工具目录/ffmpeg.exe" --ffprobe "实际工具目录/ffprobe.exe"`。macOS/Linux 使用相应系统的可执行文件路径；这两种系统尚未实机验证。旧版工具可能缺少必要能力，建议采用已验证版本；程序不会自动下载或上传素材。

5. 检查退出码和 JSON：全部完成为 `0`，逐条失败为 `1`，整体配置/工具错误为 `2`；`summary` 显示总数、完成与失败数量。`report_file` 指向本次 `index.html`。
6. 用浏览器打开报告，进入单视频页面。每个镜头有编号、起止时间和预览图；边界详情提供连续帧。
7. 播放前先在页面顶部选择对应本地原视频。未选择时按钮灰色禁用；加载成功且支持定位后启用，每次重新打开报告需重新选择。文件由浏览器本地读取。定位和停止为近似值，逐帧位置以边界图片为准。

## 输出与实际验证结果

输入视频依次经过属性读取、完整帧分析、边界判断、图片抽取和报告生成。按视觉剪辑点划分镜头：换拍摄、换机位、独立产品特写及明显跳切属于候选；连续动作、字幕或亮度变化通常不单独切分。

输出目录内每次新建独立运行目录，包含批次首页、`results.json`、单视频报告和图片。时间区间为 `[开始,结束)`，边界帧归后一个镜头，视频首帧为时间零点。每个镜头取实际时间中点所在帧作为预览，边界前后各最多两帧用于核查。

同一版本和默认配置下，三条本地素材完成处理，输出59、78、52个镜头，共189张镜头预览和186组边界图；去重后855张图片。镜头数是本次输出，不是标准答案。查看实际生成报告的方法见 README；真实画面及具体问题记录不在公开源码包内。

既有自动测试记录为85项通过、0跳过，其中34项实际调用视频工具处理临时合成数据。浏览器已验证三条报告图片加载、原视频定位与播放到末尾，以及错误文件、时间偏移、多视频轨和编码不支持情况。已浏览全部189张中间帧缩略图，并抽查边界连续帧。详细范围见 VALIDATION。

接收方可运行以下回归命令；Windows PowerShell 便携工具示例：

```powershell
$env:BEAUTYCUT_FFMPEG = "实际工具目录/ffmpeg.exe"
$env:BEAUTYCUT_FFPROBE = "实际工具目录/ffprobe.exe"
python -m unittest discover -s tests -v
```

上述路径须替换为实际可执行文件。工具缺失时34项视频集成测试会明确跳过，不能视为处理验证通过。项目开发依赖不包含 Node；本地浏览器开发验证脚本不属于业务运行前提。

## 主要取舍与局限

- 采用 Python 标准库和本地 FFmpeg/FFprobe，在普通 CPU 上顺序批处理；不依赖独显或云 API。
- 逐帧检测保留真实时间戳，支持测试覆盖的可变帧率与非零起点；不按标称帧率推算边界。
- 检测使用画面变化分数、色度变化与邻帧启发式，易于复现；渐变、叠化、连续产品运动和细微跳切仍可能误切或漏切。
- 抽图集中顺序读取，避免为每张图从头解码；每条视频约需检测和抽图两次完整读取，以控制内存和复杂度。
- 中间帧选择确定、容易验证，但实际存在模糊、过曝、遮挡或偏暗画面；未实现自动挑选清晰帧。
- 单条失败保留原因并继续，检测成功但预览失败会保留时间清单、明确记失败。硬中断可能留下未完成目录，不支持断点续跑。
- 只实际验证 Windows 和 Chrome 157。浏览器定位不是逐帧裁剪；不支持编码或时间线不可靠时给出提示，保留图片查看。
- 未建立全片人工真值或独立测试集，不报告全片准确率、精确率或召回率。用户已接受当前版本的使用结果；已知局限保留。
- 当前交付不含独立分段视频导出、语义打标、检索、重组、网页内编辑边界或问题标记。
